# Engenho Pátio: downloads

Instaladores do **Engenho Pátio** para Windows. Este repositório guarda só os arquivos de instalação, sem código-fonte. Site: [engenho.app.br](https://engenho.app.br).

## Como baixar

1. Baixe direto: [EngenhoPatio-setup.exe](https://github.com/engenho-apps/patio-releases/releases/latest/download/EngenhoPatio-setup.exe) (versão mais recente).
2. Ou abra a [página da versão mais recente](https://github.com/engenho-apps/patio-releases/releases/latest) para ver o `.msi` e as notas.
3. Execute e siga as telas. O teste de 30 dias começa na primeira abertura, com internet.

## "O Windows protegeu o computador"?

Enquanto o app não está na Microsoft Store, o Windows pode mostrar esse aviso porque o instalador ainda não tem assinatura digital. Se você baixou daqui, toque em **Mais informações** e depois em **Executar assim mesmo**. Nunca desligue proteções do Windows para instalar. Se o seu PC não mostrar a opção de continuar, fale com a gente: em breve o app estará na Microsoft Store.
